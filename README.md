# \# 🌱 GreenPulse — Environmental Analytics Dashboard

# 

# \### 📊 Power BI | Data Analytics | Sustainability

# 

# \## 📌 Project Overview

# 

# GreenPulse is an environmental analytics dashboard developed using Microsoft Power BI to explore environmental performance across Sri Lankan regions, sectors, and years.

# 

# The project demonstrates how environmental datasets can be transformed into meaningful visual insights to support sustainability analysis and decision-making.

# 

# \## 🎯 Project Objectives

# 

# \- Analyze CO₂ emissions and environmental trends.

# \- Compare renewable and fossil fuel energy consumption.

# \- Evaluate waste generation and recycling performance.

# \- Visualize geographical differences in environmental indicators.

# \- Develop interactive, user-friendly Power BI reports.

# 

# \## 🛠️ Tools \& Technologies

# 

# \- \*\*Microsoft Power BI\*\* — Dashboard development

# \- \*\*Power Query\*\* — Data cleaning and transformation

# \- \*\*DAX\*\* — Calculated measures and KPIs

# \- \*\*Data Modeling\*\* — Fact and dimension tables

# \- \*\*CSV\*\* — Environmental datasets

# 

# \## 📈 Dashboard Features

# 

# 🌍 \*\*CO₂ Emissions Analysis\*\* — Regional comparisons and yearly trends.

# 

# ⚡ \*\*Energy Consumption\*\* — Renewable versus fossil fuel analysis.

# 

# ♻️ \*\*Waste Management\*\* — Waste generated, recycled waste, and recycling performance.

# 

# 🗺️ \*\*Geographical Analysis\*\* — Sri Lankan regional CO₂ emissions map.

# 

# 📊 \*\*KPI Cards\*\* — Energy consumption, renewable energy percentage, and recycling rate.

# 

# 🎛️ \*\*Dashboard Filters\*\* — Year, region, and sector slicers for interactive exploration.
